# Calculadora Web

Actividad 3 – Unidad 1 · Desarrollo de Aplicaciones Web · Universidad Técnica de Manabí

Calculadora funcional desarrollada con **HTML**, **CSS** y **JavaScript** puro.

## Funcionalidades
- Suma, resta, multiplicación y división
- Porcentaje (%), borrar último dígito (DEL) y limpiar todo (AC)
- Operaciones encadenadas (ej. `2 + 3 × 4`, resolviendo de izquierda a derecha)
- Control de división para cero (muestra "Error")
- Corrección de errores de coma flotante
- Soporte para teclado físico (números, `+ - * /`, `Enter`, `Backspace`, `Esc`)
- Diseño adaptable a celular

## Estructura
```
calculadora-web/
├── index.html   # Estructura de la interfaz
├── style.css    # Estilos y diseño
├── script.js    # Lógica de la calculadora
└── README.md
```

## Cómo ejecutarla
Abrir `index.html` en cualquier navegador.
